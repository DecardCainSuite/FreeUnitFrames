# Free Unit Frames — changelog

Newest first. Each release's notes come from `CHANGELOG.md` at the time it was published.

## Free Unit Frames 0.10.1

- Turning combo points off now hides them for good (they could come back in combat with a target).
- "Reset tab" on the Happiness tab now resets the happiness icon, and the Indicators tab no longer resets it.
- Fresh installs: the default positions are now measured from the centre of the screen and fit a 1920×1080 screen (they were set for a very wide screen and could end up off screen).
- Cleanup: an unused copy of a shared library is no longer shipped.

## Free Unit Frames 0.10.0

- New **combo point styles**, including animated hand-drawn sticks.
- Combo points refresh instantly when you change target.
- New **Combo points** tab in the Player and Target options.
- Pet **happiness** icon on the pet frame.

Older versions: see the file list on CurseForge.
